# siviraj725-ME_FE_XFITNESSTRACKER

## Health And Fitness Tracker

A React + Vite app for logging daily calorie intake and calories burned.

### Features
- Add, edit and delete daily records (date, calories intake, calories burned, short description)
- Recent Health Statistics list
- Overall Data pie chart (always visible)
- Weekly Health Trends bar chart covering the last 7 calendar days (shown once data exists)
- Data saved in the browser's localStorage under the key `healthAndFitness`
- Responsive layout for desktop, tablet and mobile

### Tech
React, Vite, Recharts, CSS

### Run locally
```
npm install
npm run dev
```

Production build: `npm run build`
